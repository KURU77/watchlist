# 📺 視聴リスト

アニメ・映画・地上波の番組を **「お気に入り／放送予定／いつか見たい／見た」** の4つで管理する、
ビルド不要・サーバー不要の1ファイル Web アプリです。

👉 **[アプリを開く](https://kuru77.github.io/watchlist/)**　／　📄 **[使い方ガイド（PDF・3ページ）](視聴リスト_使い方ガイド.pdf)**

---

## できること

### 4つのリスト

| タブ | 内容 |
|---|---|
| ⭐ お気に入り | ★を付けたものが、状態に関係なく集まる |
| 📅 放送予定 | 放送日・公開日つき。「今日！」「明日」「あと5日」を自動表示 |
| 🕓 いつか見たい | 日付未定のストック |
| ✅ 見た | 視聴日と5段階評価つき |
| 📚 すべて | 全件を横断表示 |

お気に入りは「状態」ではなく★フラグなので、**見終わった作品もお気に入りに入れられます**。

### 種類ごとの記録

- **🍿 映画** … 公開日（日本公開日を優先）、上映時間、監督
- **🎬 アニメ** … 全何期・何期まで見たか（進捗バー＋`+1期`ボタン）、話数、放送局
- **📡 地上波** … 放送日時、放送局、シーズン数

### 🔎 データの取り込み

本の ISBN のように、**タイトルを入れるか URL を貼るだけ**で情報が入ります。

| 入力 | 取り込み元 | 入るもの |
|---|---|---|
| アニメのタイトル | AniList | 日本語タイトル / 放送開始日 / 話数 / 制作会社 / **全何期・これは何期目** |
| 映画・番組のタイトル | ja.wikipedia → Wikidata | 日本公開日 / 上映時間 / 監督 / 放送局 / シーズン数 |

映画・番組の検索は、**タイトル前方一致（prefixsearch）→ タイトル内検索（intitle:）→ 本文検索**の順に
候補を集めています。本文検索だけだと「国宝」「あんぱん」のような短い題名が
同じ語を含む別の記事に埋もれてしまうためです。
集めた記事は `pageprops.wikibase_item` で Wikidata の Q番号に変換してから中身を取ります
（リダイレクトもたどるので、URL を貼ったときに確実に解決します）。

Wikidata に分類（P31）が無い新しい作品は、記事名の「(映画)」「(2025年のテレビドラマ)」や
冒頭文から種類と公開日を推測します。逆に P31 が映画賞・映画祭・人物などを指している記事は除外します。
| `https://anilist.co/anime/154587` | AniList | 〃 |
| `https://myanimelist.net/anime/52991` | AniList（MAL ID 経由） | 〃 |
| `https://ja.wikipedia.org/wiki/君の名は。` | Wikidata | 〃 |
| `Q21697406` / `anilist:154587` / `mal:52991` | 各サービス | 〃 |

アニメの期数は、AniList の **PREQUEL / SEQUEL の関係を辿って** TV シリーズだけを数えています。
例：「葬送のフリーレン」→ *全3期のうち1期目* と判定し、フォームに自動で入ります。
分割クールが別作品として登録されているシリーズは多めに数えられるので、その場合は手で直してください。

どちらの API も **APIキー不要・CORS 対応**なので、静的ホスティングのまま動きます。
アプリ内の「どの URL を貼れる？／どの URL が保存される？」にも同じ説明があります。

### 🔗 作品に付くリンク

取り込むと、作品ごとに最大3種類のリンクが保存されます。

| | 内容 | 取得元 |
|---|---|---|
| 🔗 公式サイト | タイトルをクリックすると開く | AniList の公式サイト欄 / Wikidata の `P856` |
| ▶ 配信 | 視聴ページ。分からないものは 🔍 で作品名を検索 | 下表のとおり |
| ⓘ 取り込み元 | 情報を取ってきた AniList・Wikipedia のページ（メタ情報の末尾に小さく表示） | — |

### ▶ 対応している配信サービス

ヘッダー下の「使っている配信サービスを選ぶ」で契約中のものを選ぶと、
各作品にそのサービスのボタンが並びます。ひとつも選ばなければ、取り込みで分かった配信先だけが最大3件出ます。

| サービス | 直リンクの取得元 | 取れないときの検索先 |
|---|---|---|
| Prime Video | AniList / Wikidata `P14440` | `amazon.co.jp`（Prime Video 内検索） |
| Netflix | AniList / Wikidata `P1874` | `netflix.com/search` |
| Hulu | （なし） | `hulu.jp/search` |
| Disney+ | AniList / Wikidata `P7596` `P7595` | `disneyplus.com`（日本版） |
| U-NEXT | Wikidata `P14567` | `video.unext.jp/freeword` |
| TVer | Wikidata `P11595` | `tver.jp/search` |
| NHK+ | Wikidata `P14741`（NHK ONE） | `plus.nhk.jp/search` |

Hulu は日本版（hulu.jp）と海外版（hulu.com）で会社も配信作品も別のため、
AniList や Wikidata が持っている hulu.com の ID は使わず、つねに hulu.jp の検索にしています。

公式サイトはフォームの「公式サイト・参考URL」欄で自由に書き換えられます。
手入力で追加した作品もここに URL を入れればリンクが付きます（`http` / `https` のみ）。

## データの保存先

ブラウザの **localStorage** にだけ保存されます。サーバーには何も送信されません。

- 端末・ブラウザごとに別管理です
- 端末を移すときは右上の **書き出し / 読み込み**（JSON）を使ってください

## ローカルで使う

`index.html` をダウンロードしてダブルクリックするだけで動きます（`file://` でも取り込み機能は使えます）。

## アプリアイコン

<img src="icon.svg" width="72" alt="視聴リストのアイコン">

テレビ画面と再生マーク（見る）に、金色の星（お気に入り）を添えたアイコンです。
画面いちばん上のロゴ、ブラウザのタブ、ホーム画面に追加したときのアイコンに使われます。

| ファイル | 用途 |
|---|---|
| `icon.svg` | ファビコン・画面上部のロゴ（拡大しても劣化しません） |
| `apple-touch-icon.png` | iPhone・iPad でホーム画面に追加したとき |
| `icon-192.png` / `icon-512.png` | Android・デスクトップにインストールしたとき |
| `icon-maskable-512.png` | Android が丸などに切り抜く場合用（内容を内側に寄せてあります） |
| `site.webmanifest` | アプリ名・配色・アイコンの定義 |

`site.webmanifest` で `display: standalone` を指定しているので、ホーム画面から開くと
ブラウザのアドレスバーが出ない、ふつうのアプリのような画面になります。

作り直すときは次を実行してください（SVG と PNG が同じ数値から生成されます）。

```bash
py -3 tools/make_icon.py
```

## 使い方ガイド（PDF）

実利用者向けの手引きが [視聴リスト_使い方ガイド.pdf](視聴リスト_使い方ガイド.pdf)（A4・3ページ）です。
アプリ画面のいちばん下からも開けます。

各章は「これ以上は分割しない」かたまりとして組んであるので、
**ページの切れ目はかならず章の切れ目に来ます**（1ページ目＝表紙〜2章、2ページ目＝3〜5章、3ページ目＝6〜8章）。

作り直すときは、Python から次を実行してください（Windows の Meiryo を埋め込みます）。

```bash
py -3 tools/make_manual.py
```

章ごとの高さと、各ページの空きを確認したいときは次を実行してください。
本文の大きさや余白は `tools/make_manual.py` 冒頭の「詰め具合の調整箇所」でまとめて変えられます。

```bash
py -3 tools/make_manual.py --measure
```
